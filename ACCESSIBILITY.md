# Accessibility Statement for Zyndex

Zyndex is committed to ensuring digital accessibility for people with disabilities. We continually improve the user experience for everyone and apply relevant accessibility standards across our academic digital resource library.

---

## Conformance Status

Zyndex conforms where feasible to the **Web Content Accessibility Guidelines (WCAG) 2.1 level AA**. These guidelines explain how to make web content more accessible for people with disabilities, and user-friendly for everyone.

### Key Accessibility Features
- **Keyboard Navigation**: Critical user and admin workflows (search, login, resource viewing, catalog browsing) are accessible via standard keyboard navigation (`Tab`, `Enter`, `Space`, `Esc`).
- **Screen Reader Compatibility**: Semantic HTML5 elements (`<nav>`, `<main>`, `<header>`, `<table>`, `<section>`) and ARIA labels are implemented across interactive modals and reader viewports.
- **Visual Contrast & Hierarchy**: Text contrast ratios meet WCAG AA standards with customizable high-contrast orange-slate UI palette.
- **Responsive Text & Zooming**: UI dynamically adapts to 200% browser zooming without loss of content or breaking reading layouts.
- **Accessible PDF Previews**: PDF rendering preserves document bookmarks and readable character streams where supported by the source document.
